# Código de Conduta

Este projeto adota o **[Contributor Covenant, versão 3.0](https://www.contributor-covenant.org/version/3/0/code_of_conduct/)**
(em inglês; a tradução mais recente para o português é a da
[versão 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/)). O texto completo da 3.0 vale
para issues, pull requests, discussões e qualquer espaço do projeto; o contato da seção "Reporting an Issue" é o de
baixo.

## Em poucas palavras

- Trate todo mundo com respeito, com ou sem experiência em programação.
- Critique o trabalho, não a pessoa.
- Nada de assédio, ofensa, exposição de dados pessoais de alguém ou conteúdo sexual.
- O jogo tem humor de boteco e violência de desenho animado. Isso não autoriza ofender pessoas reais nas issues, nos
  pull requests nem no conteúdo enviado.

## Como avisar

Use o aviso privado do GitHub: aba **Security → Report a vulnerability** deste repositório, com "Conduta" no título.
A mensagem é lida só por quem mantém o projeto e fica em sigilo. Quem mantém o projeto pode pedir mudança, apagar
conteúdo, avisar ou bloquear quem descumprir o código, como descrito no Contributor Covenant.
